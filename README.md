

# Chronodex

A minimal radial time planner inspired by analog Chronodex diagrams, bullet journals, and technical editorial interfaces.

## Features

- AM/PM radial planning rings
- Color-coded time blocks
- Highlighted block markers
- Daily reminders
- In-app notice rail
- Browser notifications for reminders and block start/end events
- Category time-share dashboard
- Light and dark themes
- Localized UI: Portuguese, Spanish, English, and Japanese
- Local persistence with `localStorage`

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- SVG
- Vite
- Vitest

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Checks

```bash
npm test
npm run build
```

## Contributing

1. Fork the repository.
2. Create a branch for your change.
3. Run tests and build before opening a pull request.
4. Keep UI changes minimal, precise, and consistent with the Chronodex visual language.
